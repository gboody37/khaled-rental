# 🏠 Khaled Rental Management App

Modern property rental management web application built for Khaled.

## Features
- 📊 **Dashboard & Analytics**: Revenue overview, monthly income charts, upcoming payment splits, activity log
- 🏘️ **Properties Management**: CRUD operations for rental properties, date/day rental management, vacant/occupied status tracking
- 💰 **Payment Split System**: Flexible payment installment calculator (split annual rent 2, 3, 4, 6, or 12 times a year)
- 👥 **Renters/Tenants Management**: Active and past tenant directory, payment tracking, contact details
- 🔔 **Notification System**: Send real-time updates and reminders to Khaled (owner) or individual tenants
- 🎨 **Estate Noir Design System**: Quiet Luxury aesthetic with dark navy (#0f172a) and gold (#f59e0b) accents

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
